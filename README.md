# Finding Ledger

Finding Ledger 是面向长期 Agent 工程任务的**证据化发现账本**。它保存调试、实验和代码审查过程中形成的结论，使后续会话能够检索、核验、纠正和复用这些发现。

它要解决三个问题：上下文压缩或会话切换后遗忘已完成的排查；未经验证的假设被当成事实；历史结论在适用条件变化后被错误复用。

> **设计状态：** 本仓库当前定义目标设计与实现契约。文档描述的是目标行为；尚未实现并通过测试的能力不应被视为现有功能。

## 核心设计原则

1. **结论与证据分离。** 一条结论可以关联多个支持、反驳或补充证据；同一来源也可被多条结论复用。
2. **状态维度正交。** 证据支持情况、记录生命周期与当前适用性分别判断。
3. **按条件复用。** 项目、代码版本、运行环境和任务范围共同决定一条发现是否可直接应用。
4. **保留纠错历史。** 反证、取代和撤回留下可追溯记录，不通过静默覆盖抹去历史。
5. **按需注入。** 只注入与当前任务相关且适用范围明确的最小结论集。
6. **可追溯优先。** 记录来源、适用条件和状态变化理由，不使用未经校准的数值置信度制造精确感。
